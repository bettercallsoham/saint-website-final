# SAInT Backend API

A robust Node.js backend API for the SAInT (Students Association in Technology) website.

## 📚 Documentation

- **[Complete Documentation](./docs/README.md)** - Full API documentation, installation guide, and usage instructions
- **[Development Guide](./docs/DEVELOPMENT.md)** - Development setup, coding standards, and best practices

## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Setup environment
cp env.example .env

# Start development server
npm run dev
```

## 📁 Project Structure

```
backend/
├── docs/              # Documentation
├── config/            # Configuration files
├── middleware/        # Custom middleware
├── models/           # Database models
├── routes/           # API routes
├── utils/            # Utility functions
├── tests/            # Test files
└── uploads/          # File uploads
```

## 🛠️ Available Scripts

- `npm run dev` - Start development server
- `npm start` - Start production server
- `npm test` - Run tests
- `npm run lint` - Run ESLint
- `npm run format` - Format code with Prettier

## 📖 API Documentation

Once running, visit:
- **Swagger UI**: `http://localhost:5000/api-docs`
- **API Spec**: `http://localhost:5000/api/swagger.json`
